개인정보를 수집하지 않습니다

서버가 없고, 앱과 키보드에는 네트워크 통신 코드가 없습니다. 분석·광고·추적 도구도 없습니다. 키보드로 입력한 글자는 저장되지도, 전송되지도 않습니다. 모든 것은 기기 안에서만 처리됩니다.

수집 정보 없음 네트워크 통신 없음 입력 내용 저장·전송 없음 분석·광고·추적 없음 전체 접근 선택 사항

기능

빠르게 치는 것과 예쁘게 꾸미는 것, 둘 다

군더더기 없는 두벌식 입력 위에, 속도를 위한 제스처와 감성을 위한 테마를 얹었습니다.

✍️

제스처 퀵액션 · 단축문장

글자 키 위에서 ↑↓←→ 스와이프와 V·O·C·<·> 드로잉으로, 손을 떼지 않고 한/영 전환·복사·붙여넣기·단어 삭제를 합니다. O를 그리면 등록한 문장이 한 번에.

↔️

스페이스 트랙패드

스페이스를 꾹 누르면 자판 전체가 트랙패드가 됩니다. 손가락이 가는 대로 커서가 위아래·좌우로 움직입니다.

⌥

Fn 기호 레이어

별도 기호 페이지 대신 Fn 키 하나로. 탭하면 래치, 길게 누르면 확장 기호 페이지가 열립니다.

📖

iPhone Duo 자판 분리

펼친 안쪽 화면을 가로로 두면 < 또는 >를 그려 자판을 좌우로 나누거나 다시 붙입니다.

🎨

키보드 테마 7종 · 포인트 키캡

Apple 베이직·세라믹 화이트·스페이스 그레이·미드나잇·샌드스톤·프로스트 글래스·잉크. 백판과 키캡을 함께 맞춘 테마에, 리턴·Shift 같은 키에 색 포인트를 더합니다.

🌈

RGB 조명 3종 · 진동

누른 키가 켜지는 리액티브, 빛이 물결처럼 퍼지는 스플래시, 아래로 떨어지는 드롭다운. 퍼키 언더글로우와 햅틱 진동 스타일까지.
