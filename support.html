지원 · 사용 안내

hkeyboard를 켜는 법부터 자주 묻는 질문까지.

hkeyboard는 개인정보를 수집하지 않습니다. 네트워크 통신 코드가 없고, 입력한 글자는 저장되지도 전송되지도 않습니다. 전체 접근 허용을 켜도 마찬가지입니다. 자세한 내용은 개인정보처리방침을 확인하세요.

키보드 켜기

  1. 앱을 설치하고 한 번 실행합니다. (설정과 단축문장이 키보드로 공유됩니다.)
  2. iOS 설정 > 일반 > 키보드 > 키보드 > 새로운 키보드 추가에서 hkeyboard를 선택합니다.
  3. 텍스트 입력 중 지구본(🌐) 키를 눌러 hkeyboard로 전환합니다.
  4. (선택) 전체 접근 허용 — 키 사운드·햅틱 진동·클립보드 복사/붙여넣기를 쓰려면, 같은 화면에서 hkeyboard를 열고 전체 접근 허용을 켭니다. 켜지 않아도 입력·제스처·트랙패드·테마 등 핵심 기능은 모두 동작합니다.
  5. (선택) 다른 키보드 정리 — 지구본 전환을 단순하게 하려면, 같은 키보드 화면에서 편집을 눌러 쓰지 않는 키보드를 삭제합니다. 기본 ‘한국어’ 키보드는 남겨 두세요.

자주 묻는 질문

입력한 내용이 저장되거나 전송되나요?

아니요. 키보드로 친 글자는 입력란에 바로 들어갈 뿐, 어디에도 기록되지 않고 기기 밖으로 나가지 않습니다. 앱과 키보드에는 네트워크 통신 코드가 없고, 분석·광고·추적 도구도 없습니다. 기기에 저장되는 것은 앱에서 고른 설정과 직접 등록한 단축문장뿐입니다.

한/영은 어떻게 바꾸나요?

한/영 키 대신 제스처로 바꿉니다. 글자 키 위에서 →로 쓸면 한/영이 바뀌고, ↑는 한글, ↓는 영문입니다. 처음 실행할 때 나오는 사용법 안내에서 직접 따라 해 볼 수 있고, 설정 > 사용법 다시 보기로 다시 열 수 있습니다.

제스처 퀵액션은 어떻게 쓰나요?

글자 키 위에서 ↑ ↓ ← → 스와이프 또는 V · O · C · < · > 모양을 그리면, 연결해 둔 동작이 실행됩니다. 기본은 C 복사, V 붙여넣기, O 첫 단축문장, ← 마지막 단어 삭제입니다. 연결은 본체 앱의 퀵액션 탭에서 바꿉니다. iPhone Duo 안쪽 화면을 가로로 두면 < 나 > 로 자판을 좌우로 나누거나 다시 붙입니다.

커서는 어떻게 옮기나요?

스페이스를 꾹 누르고(약 0.45초) 있으면 자판 전체가 트랙패드가 되어, 손가락을 움직이는 대로 커서가 위아래·좌우로 움직입니다. 손을 떼면 원래 자판으로 돌아옵니다. 설정 > 스페이스바 커서 이동에서 끌 수 있습니다.

음성입력(받아쓰기)은 왜 없나요?

키보드 확장은 시스템 제약상 마이크를 직접 열 수 없습니다. 대신 iOS가 모든 서드파티 키보드 바로 아래에 그려 주는 시스템 받아쓰기 마이크가 앱 전환 없이 제자리에서 같은 일을 합니다. 키보드 하단의 시스템 마이크를 이용하세요.

암호 필드에서 시스템 키보드로 바뀌는 이유는요?

iOS가 암호 등 보안 입력 필드에서 서드파티 키보드를 자동으로 시스템 키보드로 전환하기 때문입니다. 모든 서드파티 키보드에 공통인 iOS의 보안 정책이며, 해당 입력은 애초에 hkeyboard를 거치지 않습니다.

테마나 조명은 어디서 바꾸나요?

본체 앱의 테마 탭에서 실제 키 미리보기를 보며 고릅니다. 키보드 테마(7종), 포인트 키캡, 글자 크기, 스페이스 문구, 조명(끄기·리액티브·스플래시·드롭다운)과 밝기·속도·색상, 진동 스타일을 바꿀 수 있습니다. 단축문장과 퀵액션도 본체 앱에서 편집합니다.

앱에서 바꾼 설정이 키보드에 안 보여요.

앱을 설치한 뒤 한 번은 실행해야 설정이 키보드로 공유됩니다. 바꾼 설정은 키보드를 다음에 열 때 적용되니, 키보드를 내렸다가 다시 올려 보세요.

키보드가 처음 뜰 때 높이가 잠깐 튀어요.

iOS 26에서 서드파티 키보드가 처음 표시될 때 높이가 순간적으로 바뀌는 것은 OS 차원의 알려진 현상입니다(Apple DTS 확인). 입력 동작에는 영향이 없습니다.
